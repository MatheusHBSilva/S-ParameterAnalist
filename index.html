Fluxo automático: S1P/S2P → Topp → ε′/ε″/tanδ → RFR/SVR → gráficos. Você só precisa informar os dados experimentais que o arquivo não possui.
1
Prepare os dadosTenha as medições de S11, S21, frequência, profundidade e o pH medido em laboratório.
2
Importe o arquivoUse CSV, Excel (.xlsx/.xls) ou .xl. Se o arquivo tiver varredura de frequência, o sistema reduz para 1 amostra (~4,42 GHz).
3
Preencha o que faltaInforme profundidade, umidade (θ) e pH medido. ε′, ε″ e tanδ são calculados automaticamente pelo mesmo modelo Topp do site.
4
Gere os gráficosClique em Calcular Topp + gerar modelos. O programa faz os cálculos e executa RFR, SVR e 5-fold.

S11 (dB)S21 (dB)Frequência (GHz)Profundidade d (cm)pH medido
Para as profundidades do seu estudo: 50 g → 1,9–2,5 cm e 100 g → 1,9–4,5 cm. Campos como ε′, ε″, σb, umidade e tanδ são opcionais e podem ser usados como features adicionais.
Touchstone: S1P → S11; S2P → S11 e S21. Por padrão o sistema importa 1 amostra por arquivo (ponto de ressonância ≈ mínimo de S11 / 4,42 GHz), como no artigo (N≈98). Novas importações são adicionadas às amostras já existentes (não substituem). Não use “todos os pontos de frequência” para o ML — isso gera centenas de linhas com pH quase igual e o gráfico colapsa (R² negativo). Cada amostra precisa de um pH diferente (faixa 5,0–6,5).

Avançado — fórmulas e metodologia do artigo▼
pH químico
pH = −log[H⁺]
Relação apresentada no artigo para a concentração de íons H⁺.
Permissividade complexa
ε* = ε′ − j(ε″ + σb/(2πfε₀))
Relaciona ε′, ε″ e condutividade bulk.
Teor de água
θ = −0.053 + 0.0292ε′ − 5.5×10⁻⁴ε′² + 4.3×10⁻⁶ε′³
Condutividade bulk
σb = σs(1−θ) + σωθ
Loss tangent
tanδ = Im(ε*) / Re(ε*) = ε″ / ε′
pH empírico multivariado
pH = a₀ + a₁ε′ + a₂ε″ + a₃σb + a₄σbε′ + a₅σs + a₆T
Coeficientes editáveis no bloco amarelo da seção de dados (já com valores de exemplo).
RFR
RF(X) = (1/K) Σ pHk(X)
SVR — kernel Gaussiano
SVR(X) = Σ(αᵢ−αᵢ*)K(Xᵢ,X)+b
K(Xᵢ,X)=exp(−γ||Xᵢ−X||²)
